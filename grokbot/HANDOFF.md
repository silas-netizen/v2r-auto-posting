# Grok Bot 인수인계

이 파일만 보면 인수인계됩니다. `grokbot/`는 Grok Bot 전용입니다. 카페 글 발행 프로그램과 섞지 마세요. 사용자 PC는 건드리지 마세요.

## 작업

1. 검색량 채우기 (`jobs/search-volume/`)
2. 노출 조회 (`jobs/exposure-check/`)

프로그램이 맞는 행을 모두 처리합니다. 로그를 보고, 키워드를 골라 돌리지 마세요.

매일 08:15(서울, 주말 포함). 사용자가 시트 준비됐다고 말하기 전에는 자동 실행하지 마세요.

## 시트

주소는 `config/sheets.json`에 있습니다. `newdermiss`, `patsoon`.

쓰는 열: A, G, H, I, J, K, L.  
E열 비밀번호는 읽지 마세요. 비밀번호를 입력하지 마세요. 로그인은 사용자에게 맡기세요.

## 프로그램

- 키워드 검색량 채우기
- 키워드 노출 관리 (`V2R-Exposure-Checker`) 시트 모드

Windows exe입니다. 코드는 GitHub의 이 `grokbot/`에서 받습니다. 사용자 PC에서 가져오지 마세요.

## 폴더

- `config/` — 시트 주소, 브랜드, 카페
- `jobs/` — 작업. 새 일은 여기 폴더를 추가
- `shared/` — 브라우저, 로그인, 시트 쓰기
- `logs/` — 실행 로그

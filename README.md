# V2R 카페 자동 발행

네이버 카페에 글을 올리는 Windows 프로그램입니다. 프로그램은 2개입니다.

| 프로그램 | 실행 파일 | 대상 |
|---|---|---|
| 제휴 카페 수정 발행 | `V2R-Affiliate-Revision.exe` | 씨씨앙, 양평맘 |
| 자사 카페 예약 발행 | `V2R-Immediate-Posting.exe` | 고요한 아침, 러브 인썸, 마이 웨딩 드림 |

**처음 쓰는 사람:** [사용설명서.md](사용설명서.md)를 보세요.

개발·수정용 인수인계는 [PROGRAM_HANDOFF.md](PROGRAM_HANDOFF.md)입니다.
